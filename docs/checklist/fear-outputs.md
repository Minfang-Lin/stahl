## 杏仁核的五条广播线（fear-outputs，6 幕）· Stahl 第 8 章
- 依据 Stahl 第 8 章“恐惧的神经回路”示意图：杏仁核向不同脑区的投射分别介导不同的恐惧/焦虑症状
- 杏仁核 → 导水管周围灰质（PAG，位于中脑）：运动/行为反应——僵住（freezing）、逃跑（fight/flight）、回避
- 杏仁核 → 下丘脑：激活 HPA 轴 → 皮质醇升高（内分泌反应）；链接本系列《压力的传话筒：HPA 轴》（hpa-axis）
- 杏仁核 → 蓝斑（脑干，去甲肾上腺素神经元的主要来源）：警觉、自主神经唤醒——心率加快、血压升高、出汗等
- ⚠ 心跳、血压变化的最终执行者是交感神经系统和肾上腺素/去甲肾上腺素；旁白写“再加上交感神经”，画面把心跳画在蓝斑站点里是简化
- 杏仁核 → 臂旁核（脑干）：呼吸加快；Stahl 将其与惊恐发作时的呼吸急促、窒息感联系
- 杏仁核 → 皮层（前额叶等，皮层-纹状体-丘脑-皮层环路）：担心（worry）；杏仁核 ↔ 海马：恐惧记忆的唤起/再体验
- ⚠ 画面把“皮层”和“海马”合并成一个站点，所以是“五条线”；Stahl 原图的具体分法因版本略有不同
- 惊恐发作：突发的强烈恐惧或不适，通常在几分钟内达到高峰（DSM-5 描述），伴心悸、呼吸困难/窒息感、颤抖、头晕、濒死感等；可在无真实危险时出现
- 惊恐发作本身通常不直接致命；首次出现胸闷、心悸等应就医排除心脏、甲状腺等躯体疾病（旁白：“要请医生排除心脏等身体问题”）
- SSRI/SNRI 是惊恐障碍等焦虑障碍的一线药物，通常需要数周起效；“调低整座塔的灵敏度”是比喻 ⚠（机制仍有讨论）
- 心理治疗（认知行为治疗等）是焦虑障碍的一线治疗；旁白一句带过
- β 受体阻滞剂（如普萘洛尔，未点名）阻断心脏等外周器官上的 β 肾上腺素受体，可减轻心悸、震颤等躯体症状；对担心等认知症状作用有限；常用于表演焦虑等情境 ⚠（非惊恐障碍一线药物，本集没有说它是一线）
- 本集不含剂量；页脚提醒首次发作就医、遵医嘱用药
