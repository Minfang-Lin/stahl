## 四条信号通路：从门口到细胞核（signal-cascades，6 幕）· Stahl 第 1 章
- Stahl 的四条主要信号转导通路：G 蛋白偶联受体 → 第二信使；离子通道 → 钙离子；激素（核受体）；神经营养因子（酪氨酸激酶受体）
- ① G 蛋白通路：递质结合 GPCR → G 蛋白激活 → 效应酶（如腺苷酸环化酶）→ 第二信使 cAMP → 蛋白激酶 A（PKA）→ 磷酸化靶蛋白，部分信号进入细胞核（如 CREB）；细节见 g-protein 集
- ② 离子通道通路：如谷氨酸打开 NMDA 受体（⚠ 也包括电压门控钙通道），Ca²⁺ 内流；Ca²⁺ 结合钙调蛋白（calmodulin，一个钙调蛋白结合 4 个 Ca²⁺，画面画 4 个）→ 激活钙调蛋白依赖性蛋白激酶（CaMK，如 CaMKII）→ 磷酸化靶蛋白、调节突触强度（LTP），并可影响基因转录（如 CaMKIV → CREB）
- ③ 激素通路：雌激素、甲状腺激素、皮质醇（糖皮质激素）等是脂溶性激素，进入细胞后与细胞内的核受体结合 → 激素-受体复合物进入细胞核，结合 DNA 上的激素反应元件 → 调控基因转录
- ⚠ 甲状腺激素进入细胞主要靠膜转运体（如 MCT8），并非单纯扩散；旁白“穿过细胞膜”是简化
- ⚠ 糖皮质激素受体平时在胞质中、结合后入核；甲状腺激素受体本来就在细胞核里；画面统一画成“在胞质里相遇再一起进核”
- 压力（皮质醇）、怀孕（雌激素等）、甲状腺疾病影响情绪 → 旁白“也会影响大脑和情绪”（关联表述）
- ④ 神经营养因子通路：BDNF 结合 TrkB（酪氨酸激酶受体），受体二聚化并相互（自身）磷酸化酪氨酸残基 → 激活下游激酶级联，如 Ras → Raf → MEK → ERK（MAPK 通路），以及 PI3K–Akt、PLCγ（未提）→ 影响细胞存活、突触生长和基因表达
- ⚠ Trk 家族：NGF–TrkA、BDNF/NT-4–TrkB、NT-3–TrkC；画面只写“Trk”
- 四条通路最终都汇集到蛋白质磷酸化（激酶加磷酸、磷酸酶去磷酸）和基因表达的改变
- 基因表达和新蛋白合成需要数小时到数周 → “很多精神科药物要几周才见效的原因之一”（Stahl 的经典解释之一，属于假说层面）
