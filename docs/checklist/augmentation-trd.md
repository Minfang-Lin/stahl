## 一种药不够时：增效和难治性抑郁（augmentation-trd，6 幕）· Stahl 第 7 章
- 疗效不足时先确认：剂量是否足够、疗程是否足够（通常需足量治疗数周才评估，未写具体周数）、是否按时服药、诊断是否准确（是否为双相障碍、是否共病焦虑、物质使用、甲状腺问题等）
- 两条路：几乎无效或副作用不可耐受 → 换用作用机制不同的药；部分有效 → 加药增效（augmentation）
- 增效思路：加用作用于不同靶点的药，覆盖尚未改善的症状（“症状灯”为 Stahl 症状-环路匹配思路的示意，灯的名称为示意）
- 非典型抗精神病药增效：阿立哌唑、依匹哌唑、喹硫平等（均有抑郁症增效的循证证据；⚠ 各药在国内的获批适应证以说明书为准）
- 机制：5-HT2A/5-HT2C 拮抗 → 解除对 DA、NE 的抑制；阿立哌唑、依匹哌唑为 D2/D3 部分激动剂和 5-HT1A 部分激动剂（“调光开关”）；喹硫平的活性代谢产物去甲喹硫平抑制 NET ⚠ 各药受体谱不同，旁白做了归纳
- 需留意的副作用：静坐不能（坐立不安）、镇静、体重增加（及代谢问题，未展开）
- 锂盐增效：作用于细胞内信号通路（如 GSK-3、肌醇相关通路）⚠ 增效机制未完全明确；锂盐降低自杀风险有较好证据
- 甲状腺激素 T3 增效：⚠ 机制不完全清楚，“提转速”为示意
- 安非他酮：抑制 DA、NE 转运体（NDRI）→ 可能改善精力、兴趣
- 米氮平：α2 拮抗 → NE、5-HT 释放增加；H1 拮抗 → 助眠（与 monoamine-brakes 集一致）
- 难治性抑郁：常指至少两种足量、足疗程的抗抑郁药治疗后效果不佳 ⚠ 各指南定义略有差异
- 艾司氯胺酮鼻喷雾剂：NMDA 受体拮抗 → 谷氨酸爆发 → AMPA 激活、BDNF、mTOR → 突触发生（与 ketamine 集一致）；须在医疗机构内使用
- 电休克治疗（ECT）：在麻醉（及肌松）下用短暂电流诱发一次受控的脑电发作；对难治性抑郁疗效确切、安全性良好；⚠ 作用机制仍不完全清楚（可能与神经可塑性、BDNF 等有关，未在旁白展开）；常见副作用为短期记忆问题（未写）
- 经颅磁刺激（rTMS）：线圈产生的变化磁场在皮层诱发电流，常刺激左侧背外侧前额叶，无需麻醉、患者清醒 ⚠ 旁白简写为“左侧前额叶”
- 每一步通常需观察数周再评估；不自行加药、减药或突然停药；心理治疗、规律作息同样重要
- 安全提示：出现伤害自己的想法请马上告诉身边的人、尽快去医院（旁白 + footer）；未编造热线号码
