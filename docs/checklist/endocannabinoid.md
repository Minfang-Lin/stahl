## 倒着送的信：内源性大麻素（endocannabinoid，6 幕）· Stahl 第 13 章
- 经典神经传递方向：突触前释放递质 → 突触后受体
- 内源性大麻素是逆行信使：突触后神经元去极化、Ca²⁺ 内流（或 Gq 偶联受体激活）后，由膜脂前体按需合成，不储存在囊泡中 → “临时做出”“要用的时候才现做”
- 两种主要内源性大麻素：花生四烯酸乙醇胺（anandamide，AEA）和 2-花生四烯酸甘油（2-AG）；原料是膜磷脂 → “细胞膜上的脂质原料”
- 它们从突触后扩散回突触前，激活突触前末梢上的 CB1 受体（G 蛋白偶联受体，Gi/o）
- CB1 激活 → 抑制突触前电压门控钙通道（并激活钾通道）→ 递质释放减少 → “钙通道就不爱开门了，囊泡少放递质”
- 在谷氨酸末梢上：去极化诱导的兴奋抑制（DSE）；在 GABA 末梢上：去极化诱导的抑制抑制（DSI）→ “寄给谷氨酸末梢让兴奋少一点，寄给 GABA 末梢让抑制少一点”
- ⚠ CB1 也存在于其他末梢和部位（CB2 主要在免疫细胞/小胶质细胞），未展开
- 分解：2-AG 主要由突触前的单酰甘油脂肪酶（MAGL）水解；AEA 主要由突触后的脂肪酸酰胺水解酶（FAAH）水解 → 画面把 MAGL 画在突触前末梢里、FAAH 画在突触后
- ⚠ AEA 画成从 GABA 末梢飘回突触后被 FAAH 分解、2-AG 画在谷氨酸末梢上——两种分子在哪个突触起作用的分配是为了画面演示，实际上两者都可以作用于各种末梢
- THC（Δ9-四氢大麻酚）是 CB1（和 CB2）的外源性激动剂
- ⚠ THC 在药理学上是 CB1 部分激动剂；旁白写“也能激活 CB1”，未写“完全激动”
- THC 不经 FAAH/MAGL 分解（主要由肝脏 CYP2C9、CYP3A4 代谢），高度脂溶、储存在脂肪组织中，清除较慢 → “那两位拆信员也拆不动它，要过很久才会被身体清除”
- ⚠ “要过很久”：THC 及其代谢产物清除时间差异大（偶尔使用与长期大量使用差别很大），未写具体时间
- THC 广泛、持续地激活 CB1，干扰内源性大麻素按需、局部、短暂的调节 → 急性作用包括短时记忆受损、运动协调受损、时间感改变（还有欣快、食欲增加等，未全列）
- VTA 机制：THC 激活 VTA 中 GABA 中间神经元末梢上的 CB1 → GABA 释放减少 → 多巴胺神经元去抑制 → 伏隔核多巴胺增加 → 奖赏（与阿片类“松开 GABA 刹车”的去抑制相似）
- ⚠ 青少年长期、大量使用大麻（尤其高 THC 含量）与精神病（如精神分裂症）风险增加相关；属关联，因果仍有争论 → 旁白“与精神病风险增加有关”
- CBD（大麻二酚）不直接激活 CB1、不产生欣快（“嗨”），作用机制复杂（如 CB1 负性变构调节、5-HT1A 等，仍在研究）→ 旁白一句带过“作用方式不同，不会让人‘嗨’”
