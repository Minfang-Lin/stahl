## GABA：大脑的刹车系统（gaba-system，6 幕）· Stahl 第 6 章
- GABA（γ-氨基丁酸）是中枢最主要的抑制性递质；谷氨酸是最主要的兴奋性递质
- GABA 由谷氨酸经谷氨酸脱羧酶（GAD）脱羧一步生成（去掉一个羧基，放出 CO₂）；辅因子为维生素 B6（磷酸吡哆醛，旁白未提）
- ⚠ Stahl 书中合成原料写作谷氨酸（glutamate）；谷氨酸本身可来自谷氨酰胺（谷氨酰胺酶），旁白未展开
- VIAAT（囊泡抑制性氨基酸转运体，也叫 VGAT）把 GABA 装进囊泡
- GABA 转运体（GAT）回收 GABA；GAT1 是主要的神经元型，也有胶质细胞上的 GAT（如 GAT3）；旁白写“旁边的胶质细胞也会收一些”
- GABA 转氨酶（GABA-T）分解 GABA，存在于神经元和胶质细胞；画面把 GABA-T 画在末梢里，是简化
- 噻加宾（tiagabine）是选择性 GAT1 抑制剂，抗癫痫药；氨己烯酸（vigabatrin）是 GABA-T 的不可逆抑制剂，抗癫痫药（婴儿痉挛症、难治性局灶性癫痫；有视野缺损风险，旁白未提）
- ⚠ 两药在中国大陆的上市情况需核实；旁白只称“两种抗癫痫药”
- GABA-A：配体门控氯离子通道，由五个亚基组成；最常见组合为 2 个 α、2 个 β、1 个 γ（如 α1β2γ2）
- GABA 的结合位点在 β 与 α 亚基的界面（β+/α−），每个受体两个；苯二氮䓬结合位点在 α 与 γ 的界面（α+/γ2−）——已在《杏仁核的警报器》《离子通道》中讲过，本集只点到
- 画面上“从上往下看”的五个圆按 γ-β-α-β-α 排列，与常见拓扑一致；氯离子从中央孔流入为示意
- 氯离子内流使神经元超极化/更难被激发；GABA-A 反应为毫秒级（快速抑制）
- ⚠ α 亚基分工（主要来自基因敲入小鼠研究，是大致规律）：α1 — 镇静、催眠（也与部分抗惊厥、顺行性遗忘相关）；α2、α3 — 抗焦虑（α2 还与肌松相关）；α5 — 主要在海马，与学习记忆相关
- 苯二氮䓬作用于含 α1、α2、α3、α5 的 GABA-A（需 γ2），所以同时有抗焦虑、镇静和记忆方面的影响
- ⚠ 唑吡坦等“Z 药”对含 α1 的受体有选择性（偏好），主要用于入睡；“偏爱 α1”为相对选择性，不是只作用于 α1
- GABA-B：G 蛋白偶联受体（Gi/o），作用较慢而持久；突触后开放 GIRK 钾通道（K⁺ 外流、超极化），突触前抑制电压门控钙通道、减少递质释放（也可作自身受体/异身受体）
- 巴氯芬（baclofen）是 GABA-B 激动剂，用于痉挛（肌肉痉挛状态）
- ⚠ 羟丁酸钠（sodium oxybate，GHB 钠盐）用于发作性睡病（猝倒、日间嗜睡）；Stahl 认为其作用于 GABA-B（及可能的 GHB 位点）
- GABA-C（现多归为 GABA-A ρ 亚型，主要在视网膜）本集略去
- GABA 中间神经元对大量锥体神经元提供抑制，协调其放电时序，参与脑节律（如 γ 振荡）；“交警”是比喻
- GABA 抑制不足 → 兴奋过度：与焦虑、失眠、癫痫易感相关（机制框架，不是单一病因）
- 画面中放电记录、兴奋度条均为示意，不代表真实数据；本集不含剂量
