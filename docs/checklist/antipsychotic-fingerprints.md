## 抗精神病药的受体指纹（antipsychotic-fingerprints，6 幕）· Stahl 第 5 章
- 结合亲和力：药物与受体结合的强弱（常用 Ki 表示，Ki 越小亲和力越强）；亲和力越强，达到同样受体占有率所需的药物浓度越低 → 第 1 幕“药量升高时先占握力强的门”
- ⚠ 第 1 幕的“某药”是虚构示例，六根绳子的粗细不代表任何真实药物
- ⚠ 全集所有指纹条的高低都是按 Stahl 书中各药“受体结合图”（pharmacologic icons / binding profiles）的定性印象画的示意，只表示相对强弱，不是精确的 Ki 或占有率；不同实验室的数据差别也很大。片中和页脚都注明“示意”
- 条形图列名：2A = 5-HT2A，1A = 5-HT1A；“7”= 5-HT7；“回收”= SERT/NET；D3 只在卡利拉嗪上画
- Stahl 按结构/名称把第二代抗精神病药分成几个“家族”来记忆：“平”（-pines：氯氮平、奥氮平、喹硫平、阿塞那平）、“酮/哌酮”（-dones：利培酮、帕利哌酮、鲁拉西酮、齐拉西酮等）、“哌唑/拉嗪”（-pips/-rips：阿立哌唑、依匹哌唑、卡利拉嗪）
- “平”类：5-HT2A 亲和力高于 D2；氯氮平 D2 亲和力较低；⚠ H1 阻断在氯氮平、奥氮平、喹硫平较强，阿塞那平中等；M1 阻断在氯氮平、奥氮平明显，喹硫平较弱（主要来自代谢物去甲喹硫平），阿塞那平几乎没有 → 旁白写“不少成员还紧紧抓着 H1，氯氮平和奥氮平还抓着 M1”
- H1 阻断与镇静、食欲增加/体重增加有关（5-HT2C 阻断等也参与，片中未展开）；M1 阻断与口干、便秘、视物模糊、认知影响等有关；α1 阻断与直立性低血压、头晕有关（与《D2 受体的门卫》一集一致）
- ⚠ “这一家比较常见嗜睡和体重增加”：氯氮平、奥氮平最明显；阿塞那平体重影响相对较小。是家族层面的概括
- “酮”类：D2 和 5-HT2A 亲和力都很高；M1 几乎无亲和力
- 鲁拉西酮：5-HT7 拮抗亲和力很高，还有 5-HT1A 部分激动；H1、M1 亲和力很低
- 齐拉西酮：抑制 SERT 和 NET（⚠ 亲和力中等，其临床意义不确定；Stahl 称之为“SNRI 样”作用），并有 5-HT1A 部分激动
- ⚠ 利培酮、帕利哌酮的 D2 作用强，高剂量时锥体外系反应和泌乳素升高更常见（帕利哌酮是利培酮的活性代谢物 9-羟利培酮）；旁白只写“要留意”
- “哌唑/拉嗪”类：阿立哌唑、依匹哌唑、卡利拉嗪都是 D2（和 D3）部分激动剂，对 D2 亲和力很高 → 指纹里 D2 画成“半满”的斜纹格子
- ⚠ 依匹哌唑的 D2 内在活性低于阿立哌唑（“推得更轻”），5-HT2A 拮抗和 5-HT1A 部分激动相对更强，α1 亲和力也较高
- 卡利拉嗪对 D3 的亲和力高于 D2（与《多巴胺的五扇门》一致）
- ⚠ “这一家对 H1、M1 抓得不紧”：M1 几乎没有；H1 为中等偏弱（依匹哌唑、卡利拉嗪的 H1 亲和力中等），片中画成中等高度
- 5-HT1A 部分激动：阿立哌唑、依匹哌唑、卡利拉嗪、鲁拉西酮、齐拉西酮、喹硫平（去甲喹硫平）、氯氮平等都有不同程度的 5-HT1A 部分激动作用
- ⚠ 第 5 幕的接力（皮层锥体神经元上的 5-HT1A 被激活 → 神经元抑制 → 投射到脑干的谷氨酸减少 → 脑干 GABA 中间神经元对多巴胺神经元的抑制减弱 → 纹状体多巴胺释放增加 → 与药物竞争 D2、减少锥体外系反应）是 Stahl 的简化模型，与 5-HT2A 拮抗那条通路类似；临床意义仍有争议，旁白写“一种解释是”“可能”
- ⚠ 5-HT1A 部分激动“可能帮助改善情绪和焦虑”：依据包括丁螺环酮（5-HT1A 部分激动剂）用于焦虑，以及部分药物用于抑郁的增效；属机制推测，旁白写“还在研究中”
- 第 6 幕的“指纹 A”“指纹 B”是虚构示例（A：H1、M1、α1 高；B：D2、5-HT2A 高），不对应具体药物
- ⚠ “换药就是换指纹，所以疗效和副作用有时会不一样”：受体谱差异是换药后反应不同的解释之一，个体差异（代谢、依从性、诊断等）同样重要；强调换药由医生决定
- 本集没有写任何剂量；页脚提醒遵医嘱，不要自行停药或换药
