## 组胺：清醒管家和它的四扇门（histamine，7 幕）· Stahl 第 10 章
- 脑内组胺神经元的胞体只位于下丘脑后部的结节乳头核（tuberomammillary nucleus, TMN），纤维广泛投射到皮层、丘脑、基底前脑、脑干等全脑区域
- 组胺神经元放电与觉醒状态相关：清醒时放电最多，非 REM 睡眠时明显减少，REM 睡眠时几乎停止（旁白简化为“人睡着以后几乎停工”）
- 本集不重复《睡眠开关和叫醒员》《开关卡不住》里的 VLPO 跷跷板和食欲素内容
- H1 受体：突触后 G 蛋白偶联受体，偶联 Gq（→ 磷脂酶 C → IP3/DAG），激活后神经元兴奋性增加，是组胺促醒的主要受体；外周 H1 参与过敏反应（血管通透性、瘙痒等）
- 阻断 H1 → 嗜睡、镇静；并与食欲增加、体重上升有关（下丘脑 H1 参与饱腹信号，Stahl 把 H1 拮抗列为抗精神病药/抗抑郁药致体重增加的机制之一，常与 5-HT2C 拮抗一起提及）
- ⚠ H1 阻断与体重增加的关系主要来自相关性和药理学推断，机制细节仍在研究；旁白用“可能”
- 画面/旁白举例：老一代抗组胺药苯海拉明；抗抑郁药米氮平；抗精神病药奥氮平、喹硫平——都有较强的 H1 拮抗作用（氯氮平也很强，未点名）
- 第一代抗组胺药脂溶性高，易通过血脑屏障；第二代（氯雷他定、西替利嗪、非索非那定等）较难进入中枢，且部分是 P-糖蛋白（外排转运体，画面里的“门卫”）的底物，被泵回血液
- ⚠ 各第二代药物的 P-gp 底物程度不同（非索非那定明确，西替利嗪、氯雷他定程度有争议），旁白写“有的还会被‘门卫’送回血里”；西替利嗪在部分人仍可引起轻度嗜睡，旁白写“通常更少犯困，但并不是完全不会”
- H3 受体：主要位于组胺神经元末梢的突触前自身受体（负反馈，减少组胺合成和释放）；也作为异身受体位于乙酰胆碱、去甲肾上腺素、多巴胺、5-HT、谷氨酸、GABA 等末梢，抑制它们的释放（画面只画了 ACh/NE 末梢）
- H3 偶联 Gi/o；具有较高的组成性（自发）活性 —— 旁白说“就算没有组胺来按，自己也会轻轻踩着一点刹车”
- 替洛利生（pitolisant）：H3 拮抗剂/反向激动剂，增加组胺释放，并增加皮层乙酰胆碱、去甲肾上腺素（及皮层多巴胺）释放；用于发作性睡病的日间过度嗜睡（部分国家也用于猝倒）
- ⚠ 替洛利生对纹状体/伏隔核多巴胺影响不大（成瘾性低的理由之一），本集未展开
- H2 受体：主要在胃壁细胞，促进胃酸分泌，偶联 Gs；法莫替丁是 H2 拮抗剂（胃药）。脑内也有 H2，本集未展开
- H4 受体：主要在免疫细胞（肥大细胞、嗜酸性粒细胞、T 细胞等），与炎症、趋化和瘙痒有关；H4 药物仍在研究中
- 组胺受体共四种：H1、H2、H3、H4
- 本集不含剂量；副作用问题提醒告诉医生，不自行停药换药
