## 体重和血糖：抗精神病药的代谢风险（antipsychotic-metabolic，6 幕）· Stahl 第 5 章
- Stahl 的“心血管代谢风险”框架：抗精神病药 → 食欲增加、体重增加 → 胰岛素抵抗 → 血脂异常（尤其空腹甘油三酯升高）、高血糖、糖尿病 → 心血管事件风险升高
- 第一步：下丘脑摄食中枢的 H1 和 5-HT2C 受体被阻断 → 饱腹信号减弱 → 食欲增加 → 体重增加
- ⚠ “同时阻断 H1 和 5-HT2C 与体重增加最相关”是 Stahl 采用的主要假说（相关性证据为主）；旁白写“一般认为”
- ⚠ 5-HT2C 激动在下丘脑与 POMC 神经元、饱腹信号相关；H1 阻断增加食欲；画面“饱腹灯”由两扇门共同点亮是简化示意
- 腹部（内脏）脂肪增加与胰岛素抵抗关系尤其密切；胰岛素抵抗：胰岛素作用减弱，葡萄糖进入肌肉/脂肪细胞减少、肝糖输出增多，血糖升高；常伴甘油三酯升高
- 画面把葡萄糖转运体（GLUT4）画成“葡萄糖门”、胰岛素画成“钥匙”，是示意
- ⚠ 第二步：Stahl 提出假设的“受体 X”——某些药物可能直接作用于胰腺、肝脏、骨骼肌等处的某种（未知）受体，快速引起胰岛素抵抗，独立于体重增加；这一受体尚未被识别，属于假说
- 临床上确实观察到部分患者在体重明显增加之前就出现血糖、甘油三酯升高（尤其氯氮平、奥氮平）
- ⚠ 少数患者可在用药后较短时间内出现严重高血糖、糖尿病酮症酸中毒（DKA）甚至高渗状态，可危及生命；机制未完全明确（可能与胰岛 β 细胞功能受损等有关）
- DKA 机制（简化）：胰岛素作用严重不足 → 细胞不能利用葡萄糖 → 脂肪大量分解 → 酮体生成 → 代谢性酸中毒
- DKA/严重高血糖的警示症状：明显口渴、多尿、乏力，恶心呕吐、腹痛、呼吸深快（Kussmaul 呼吸）、呼气有烂苹果味、意识改变——出现时应立即就医
- ⚠ 各药代谢风险分级（Stahl 及多数指南的大致分级，个体差异大）：较高——氯氮平、奥氮平；中等——喹硫平、利培酮（帕利哌酮、伊潘立酮等也常列中等）；较低——阿立哌唑、齐拉西酮、鲁拉西酮（依匹哌唑、卡利拉嗪、鲁美哌隆等也常列较低）
- 画面柱高为示意，不代表具体数值
- 监测项目（参考美国 ADA/APA 共识等）：体重和 BMI、腰围、血压、空腹血糖或糖化血红蛋白（HbA1c）、空腹血脂；用药前测基线，用药后前几个月更频繁（如体重每月），之后定期（如每季度/每年，依指南）——旁白未写具体间隔
- 处理：生活方式干预（饮食、运动）、换用代谢风险较低的药物、加用二甲双胍等（均由医生决定）；不要自行停药
