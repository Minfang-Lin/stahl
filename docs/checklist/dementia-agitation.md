## 痴呆里的激越和幻觉（dementia-agitation，6 幕）· Stahl 第 12 章
- ⚠ Stahl 的模型：痴呆的神经病理（淀粉样斑块、tau 缠结、路易体、血管性病变等）损伤前额叶皮层神经元及其连接 → 前额叶对杏仁核等边缘/情绪中枢的“自上而下”抑制性控制减弱 → 冲动“自下而上”地直接转化为行为 → 激越、攻击；这是理论模型，画面的“刹车手”“盾”是比喻
- 激越表现：坐立不安、来回走动、言语或身体上的攻击、大声喊叫、反复要求等；“我要回家”是常见表现之一，画面举例
- ⚠ 残存回路中 5-HT、去甲肾上腺素、多巴胺的失衡：Stahl 描述为神经递质“失衡”，具体哪种偏多偏少因人而异、证据有限，旁白只写“有的偏多、有的偏少”
- ⚠ 痴呆相关精神病（幻觉、妄想）：一种假说是病变使皮层 5-HT2A 信号相对过强（与帕金森病精神病类似）；视幻觉在路易体痴呆中尤其常见；“看到小猫”是画面举例
- 可逆/可治疗的诱因（先排查）：疼痛、感染（尿路感染、肺炎等）、便秘/尿潴留、睡眠紊乱、环境或照护者变化、药物副作用（尤其抗胆碱药、镇静药等）、谵妄；很多激越是“无法表达的不适”
- 非药物干预是首选：减少过度刺激、温和安抚、不争辩、规律作息、白天光照和活动、照护者支持与培训（如 DICE 方法等，未提名）
- 药物：症状严重、有伤害自己或他人风险、非药物干预无效时，可在医生评估下短期使用某些抗精神病药（如利培酮在部分国家获批用于阿尔茨海默病的严重攻击）
- ⚠ 依匹哌唑（brexpiprazole）2023 年获美国 FDA 批准用于治疗阿尔茨海默病痴呆相关的激越（首个该适应证药物）；国内该适应证的状态以最新信息为准，旁白只写“已在美国获批”
- 黑框警告：所有抗精神病药（第一代和第二代）用于痴呆相关精神病的老年患者，死亡风险增加；多项研究显示脑血管不良事件（卒中）风险也增加 → 旁白“有增加卒中和死亡风险的警告”
- 原则：由医生权衡利弊、尽量短期使用、定期复查减停；家属不要自行给药；路易体痴呆/帕金森病患者对抗精神病药格外敏感（见“不止阿尔茨海默：其他痴呆”一集，本集未重复）
- 其他在研或国外使用的药物（如西酞普兰、右美沙芬-安非他酮等）未提及；未出现任何剂量
