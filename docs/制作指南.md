# 脑内小剧场 · 制作指南

每一集是一个文件夹：`<id>/scene.js`（动画）+ `<id>/index.html`（单独播放页）。结构和「身体小剧场」一样，画风换成**日系治愈漫画风**：奶油纸底、樱花淡彩、暖棕紫细线条、大眼睛的 Q 版拟人角色（参考《工作细胞》：每种分子都是穿制服、帽子上有名牌的小人）。

参考实现：`synapse/scene.js`（第 1 集，突触邮局）。新做一集时先通读它。

## 硬性规则

- **只改自己的文件夹**。`shared/` 下的引擎、样式、目录和根目录 `index.html` 由维护者统一改；需要引擎没有的画法，就在自己的 `scene.js` 里写本地函数。
- 代码要兼容 **Chrome 61 / ES2017**：不用 `?.`、`??`、对象展开 `{...x}`、`Array.prototype.at/flat`、`replaceAll`、`Object.fromEntries` 等。写完运行 `node tools/check_compat.js <id>/scene.js`。注意：自己起的方法名也别叫 `.at(`，检查器会误报。
- `CH` 数组里每一幕的旁白写成 `text: "……"`（不加引号的键名、双引号字符串、不要换行），`make_audio.py` 靠这个格式读旁白。
- 不用外部图片和网络请求，全部用 canvas 画。
- 医学内容要准确、克制：机制讲清楚，但**不写具体剂量**，不鼓励自行用药；涉及停药、自杀风险等内容，提醒“遵医嘱”“及时求助”。把这一集用到的每一个数字、每一条容易出错的说法写进 `docs/checklist/<id>.md`，不确定的标 ⚠。

## scene.js 的骨架

```js
Anima.register("<id>", {
    "title": "短标题（展厅卡片上的名字）",
    "tag": "页头小标签，比如 抗抑郁药",
    "headline": "页头大标题，用【】包住要高亮的字",
    "lede": "页头简介，两三句话",
    "summary": "展厅卡片上的一句话简介",
    "chapter": "对应 Stahl《精神药理学精要》第 N 章 · 章名",
    "footer": "可选，补在免责声明后面的一句就医提示",
    "canvasLabel": "给读屏软件的画面描述",
    "regions": ["pfc"],        // 大脑地图上的脑区，见下表
    "parts": ["mood"],         // 按章节的分组，见下表
    "cast": ["5HT", "pump"],   // 出场角色（Anima.CAST 的 key），角色图鉴里会链接过来
    "color": "#8fdcc4"         // 这一集的主题色
  }, () => {
  const CH = [
    { title: "幕标题", /* 状态目标值…… */ pill: ["标签", "数值"], text: "旁白……", fact: "一句话知识点", labels: [] },
  ];
  const S = { /* 会在幕与幕之间平滑过渡的状态，初始值 */ };
  // ……
  return {
    chapters: CH, state: S, dur: 13, accent: "#色值",
    titleCard: { lines: ["片头第一行", "第二行"] },
    sync(e) { W = e.W; H = e.H; time = e.time; cur = e.cur; },
    update, draw,
  };
});
```

- 引擎每帧把 `S` 里每个键平滑地拉向 `CH[cur]` 里同名键的值（大约 1～2 秒过渡），适合做“图层淡入淡出”“数值慢慢变化”。
- 同一幕里的分镜时间线，用本幕已播放秒数 `lt` 来排（参考 `synapse` 的 `update()` 和 `prog(t0, d)`）。一幕默认 13 秒，旁白长可以改 `dur`。
- `W`、`H` 是舞台大小：桌面 16:9，手机约 1000:820。**所有尺寸都按 `H`（或 `W`）的比例写**，别写死像素。手机上要能看清：角色头半径一般 `H * 0.035～0.05`。
- 画面顶部左右两个数值胶囊 `pill()` 占着，标注和气泡引擎会自动避开；自己排版时用 `Anima.topSafe()` 取顶部安全高度，`Anima.narrow` 判断是不是手机窄屏。胶囊文字尽量短（标签 2～4 字、数值 6 字以内），手机上两个才能排在一行。
- 不同的画面（view）各用一个状态键淡入淡出（`v0`、`v1`…），不要用一个数字键表示“第几个画面”，否则跳幕时会经过中间的画面。

## 引擎 API（`Anima.xxx`）

颜色：`Anima.C`（`ink` 文字色、`line` 线条色、`rose`、`sakura`、`sky`、`mint`、`lemon`、`lav`、`peach`、`gold`、`good`/`warn`/`bad` 等）；`mix(c1, c2, t)` 混色，`alpha(hex, a)`。

### Q 版角色
`chara(x, y, s, opts)`：(x, y) 是**脚底中心**，s 是头的半径，整个人约 3.1s 高。
- `who`: `"DA"` 多巴胺、`"5HT"` 血清素、`"NE"` 去甲肾上腺素、`"GABA"`、`"Glu"` 谷氨酸、`"ACh"` 乙酰胆碱、`"His"` 组胺、`"Ox"` 食欲素、`"neuron"` 神经元居民、`"pump"` 转运体回收员、`"MAO"` 清扫员、`"AChE"` 剪刀手、`"drug"` 药物访客（胶囊帽，`label` 写药名，`hatColor`/`hatColor2` 改胶囊两半的颜色）
- `eyes`: `open` `happy` `closed` `sleepy` `wide`(吃惊) `teary`(含泪) `sparkle`(星星眼) `dizzy`(晕) `x`(><) `angry`
- `mouth`: `smile` `open` `grin` `flat` `sad` `o` `cat` `wavy`(紧张)
- `arms`: `down` `wave` `up`(欢呼) `hold`(抱着东西) `point` `shh`(嘘) `carry`(举过头顶) `fist` `hug`
- `item`: `letter` `book` `broom` `star` `net` `lamp` `scissors` `shield` `key`
- `tag`: 脚下的白色名牌（胶囊帽上的字在手机上太小，药名写在这里更清楚）
- `walk`: 走路相位（比如 `time * 9`），`jump`: 往上跳几个头高，`dir`: 1 朝右 / -1 朝左，`brow`: `worry`/`angry`，`gray`: true 或 0～1 变灰（没精神、被抑制；是把颜色往灰色混，不用 `ctx.filter`，自己画的东西也别用 `ctx.filter`，软件渲染下很慢），`alpha`，`label` 覆盖帽子名牌（比如 `"D2"`、`"SSRI"`），`hair`/`cloth`/`eye`/`hatColor` 可以覆盖颜色造出新角色。
- 头半径 < 6 像素时自动画成简化的小不点。

### 漫画效果
- `say(key, on, tx, ty, bx, by, text, kind)`：对话气泡。(tx, ty) 是说话人的头顶（尾巴朝它），(bx, by) 是气泡中心。`kind`: `say` / `shout`(爆炸框) / `think`(云朵) / `box`(旁白方框)。`key` 全集唯一，`on` 为 false 时自动淡出。
- `callout(key, on, tx, ty, lx, ly, text)`：名词标注（虚线 + 圆角标签）。
- `pill(x, y, label, value, color, alignRight)`：角落数值胶囊。
- `emote(kind, x, y, s)`：头顶符号 `!` `?` `sweat` `anger` `heart` `note` `zzz` `gloom` `sparkle` `bulb`。
- `sfx(text, x, y, fs, color, rot, a)`：拟声词大字（“啵！”“咻——”）。
- `sparkle(x, y, s, a)`、`sparkles(cx, cy, r, n, a, seed)`：闪光星；`glow(x, y, r, color, a)`：柔光；`speedLines(cx, cy, rIn, n, a)`：集中线；`tone(x, y, w, h, color)`：网点。
- 背景：`wash(top, bottom)` 水彩渐变，`bokeh(n, color, a, seed)` 光斑，`petals(n, a, seed)` 樱花瓣。
- 小物件：`face(x, y, s, mood)` 给蛋白质、器官的简单小脸；`heart`、`sweat`、`bolt`、`text(t, x, y, fs, color, align)`。

### 突触零件
- `terminal(cx, y0, w, h, color)`：从上方垂下的突触前末梢，返回 `{ bot, left, right }`。
- `postMembrane(y, color, { face, faceX, mood })`：下方的突触后膜。
- `receptor(x, y, s, color, act, { shape: "round"|"square"|"tri", label, dir })`：膜上的受体“门”，`act` 0～1 发光打开；返回 `{ site }`（结合位点坐标，角色站在这里表示“插进钥匙”）。
- `transporter(x, y, s, color, spin, blocked)`：回收旋转门，`blocked` 时贴“暂停回收”封条。
- `vesicle(x, y, r, color, n, seed)`：囊泡；`ion(x, y, r, label, color)`：离子；`spark(points, t, s, color)`：沿折线跑的电信号。

## 画面和叙事的建议

- **一幕只讲一件事**，画面要能“看图说话”：先用角色的动作和表情演出来，再用 1～3 个标注点名词。旁白 100～170 字，`fact` 一句话。
- 比喻要贯穿全集，并和其他集一致：递质 = 送信的快递员，受体 = 带锁的门（钥匙孔形状对应递质），转运体 = 回收门，酶 = 清扫员/剪刀手，药物 = 戴胶囊帽的访客（帽子上写药名或类别），通路 = 铁路/公路，脑区 = 小镇里的不同街区。
- 画风：浅色水彩底 + 光斑 + 少量樱花瓣；线条用 `Anima.C.line`，不要纯黑粗描边；多用星星、爱心、汗珠、集中线等漫画符号表达情绪。坏事发生时可以让角色变灰、流泪、出现阴沉竖线，但整体保持治愈、不吓人。
- 标注和气泡别互相压住，也别压住角色的脸；手机竖屏（约 1000:820）也要检查。

## 检查

```bash
npm install                                   # 装 playwright 和 acorn
node tools/check_compat.js <id>/scene.js      # Chrome 61 兼容性
node tools/shoot.js <id>/index.html /tmp/<id> 1200 900 3,8,12     # 桌面：每幕第 3、8、12 秒各截一张
node tools/shoot.js <id>/index.html /tmp/<id>-m 390 844 3,8,12    # 手机
```
截图工具等的是本幕实际演到的秒数（`Anima.sceneTime`），机器慢也不会截错时刻；它会打印页面报错。每一幕都看一遍截图，再改。

## 脑区（`regions`）

| key | 名字 |
|---|---|
| `pfc` | 前额叶皮层 |
| `striatum` | 纹状体 |
| `nac` | 伏隔核 |
| `amygdala` | 杏仁核 |
| `hippo` | 海马 |
| `hypo` | 下丘脑和垂体 |
| `midbrain` | 中脑（腹侧被盖区、黑质） |
| `brainstem` | 脑干（中缝核、蓝斑） |
| `synapse` | 突触（放大看） |

和大脑地图上的脑区都不沾边的集（比如讲肝脏代谢的），`regions` 写空数组，它只出现在“按章节”里。

## 章节分组（`parts`）

`basics` 基础篇（第 1～3 章）· `psychosis` 精神病与抗精神病药（第 4～5 章）· `mood` 心境障碍与治疗（第 6～7 章）· `anxiety` 焦虑与创伤（第 8 章）· `pain` 慢性疼痛（第 9 章）· `sleep` 睡眠与觉醒（第 10 章）· `adhd` 注意缺陷多动障碍（第 11 章）· `dementia` 痴呆（第 12 章）· `addiction` 冲动、强迫与成瘾（第 13 章）

## 上线一集

1. 在根目录 `index.html` 末尾的剧集列表里加 `<script src="<id>/scene.js"></script>`。
2. 如果它在 `shared/catalog.js` 的 `planned` 里，删掉。
3. 把 `docs/checklist/<id>.md` 并进 `docs/医学核对清单.md`（按集的顺序拼接即可）。
4. `python3 build_xhs.py` 重新打包小红书小工具。
